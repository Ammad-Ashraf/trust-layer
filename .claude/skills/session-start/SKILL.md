# Session start

1. Read the last 5 lines of `lab-log.md`.
2. Read `docs/roadmap.md`: find the milestone marked 🟨 (or the first ⬜) and the unchecked items under "This week".
3. List any decision in `docs/decisions/` with status `open` whose "Decide by" date has passed or is within 3 days.
4. If the work touches code, re-read `docs/engineering-standards.md`.

Then reply in this shape, and nothing more:

- **Last time:** one line from the lab log.
- **Now:** the current milestone and the one thing to measure or finish today.
- **Needs your call:** open decisions due soon, if any.
