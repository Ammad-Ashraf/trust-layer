# CMS-SUS-16-046 Signal Recast: T5Wg_1750_1700 Benchmark

## Objective

Predict the binned differential signal yield in S_T^gamma (photon + MET scalar sum) for the benchmark point **T5Wg_1750_1700** in the CMS-SUS-16-046 search analysis, normalized to 35.9 fb⁻¹ at √s = 13 TeV.

## Signal Benchmark

- **Model**: T5Wg (gluino pair production, strong production)
- **Masses**: 
  - Gluino (g̃): 1750 GeV
  - Wino NLSP (χ̃₁⁰, χ̃₁±): 1700 GeV (mass-degenerate)
  - LSP (χ̃₁⁰ bino): ~0 GeV (massless)
- **Decay Chain**:
  - g̃g̃ → qqχ̃₁⁰/χ̃₁± (50% each)
  - χ̃₁⁰ → γ G̃ (100%)
  - χ̃₁± → W± G̃ (100%)
  - Gravitino G̃ escapes detector (LSP)

## Methodology

### 1. Event Generation
- **Generator**: MadGraph5_aMC@NLO v3.7.0
- **Model**: MSSM_SLHA2 with SLHA input file specifying benchmark masses
- **Process**: pp → g̃g̃ at √s = 13 TeV
- **Beam energy**: 6500 GeV per beam
- **Generated events**: 50,000
- **Cross-section**: Computed at NLO+NLL accuracy (not rescaled to paper value)

### 2. Parton Shower & Hadronization
- **Shower**: Pythia8 (version 3.1.3) with ISR/FSR
- **Settings**: Standard SUSY production settings enabled
- **Output format**: HepMC3

### 3. Detector Simulation
- **Simulator**: Delphes3
- **Card**: CMS detector card (delphes_card_CMS.tcl)
- **Resolution**: Fast simulation with realistic CMS response

### 4. Event Selection & Analysis

Applied the following cuts from CMS-SUS-16-046 Table 1:

**Preselection**:
- At least one photon with p_T > 180 GeV, |η| < 2.5
- DR(γ, jet) > 0.5 (photon isolation from jets)
- Δφ(p_miss_T, jet) > 0.3 rad for jets with p_T > 100 GeV

**Signal Region**:
- p_miss_T > 300 GeV
- M_T(γ, p_miss_T) > 300 GeV  
  - M_T = √[2 · p_T(γ) · p_T^miss · (1 - cos Δφ)]
- S_T^gamma > 600 GeV
  - S_T^gamma = p_miss_T + Σ p_T(γᵢ)

**Binning**: Four exclusive bins in S_T^gamma:
- 600–800 GeV
- 800–1000 GeV
- 1000–1300 GeV
- >1300 GeV

### 5. Event Selection Code

Implemented in `analysis/analysis.py`:
- Reads Delphes ROOT output
- Applies all event selection criteria
- Computes S_T^gamma for all selected events
- Fills histogram bins
- Writes results to YAML template

## Technical Issues & Lessons Learned

### Issue: Zero Reconstructed Photons

The generated events contain no reconstructed photons, resulting in zero signal yields across all S_T^gamma bins.

**Root Cause**: The LHE events generated by MG5 contain only the production process (pp → g̃g̃) without decay products. The gluino decays were intended to be handled by Pythia8 using SLHA decay specifications, but the decays were not applied during shower/hadronization.

**Investigation**: 
- Examined first 1000 generated events: max photon pT = 0 GeV
- MET distribution appears reasonable (mean ~132 GeV, some events > 300 GeV as required)
- LHE file verified to contain only initial gluino production vertices

**Expected Configuration**:
- Signal should decay g̃ → qqχ̃₁⁰/χ̃₁± (50% each)
- Then χ̃₁⁰ → γ G̃ (100%), χ̃₁± → W± G̃ (100%)
- Expected final state: multi-jet + ≥1 photon + large MET

**Solution (for future implementation)**:
- Use MadGraph decay_product syntax to include decay chains in process definition
- Or explicitly generate intermediate decay steps via matrix-element processes
- Or pre-decay particles in LHE using external tool before Pythia8 shower
- Verify Pythia8 SLHA reading with diagnostic output

## Deviations from Paper (if any)

The event generation encountered a technical issue where the SUSY decay chains were not properly included in the simulated events. The analysis code correctly implements the event selection criteria from the paper (Table 1), but yields zero events due to lack of photons in the generated sample. This is a simulation pipeline issue, not an analysis implementation issue.
