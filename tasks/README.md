# Tasks

One folder per Collider-Bench task, named with the full task id (e.g. `sus-16-034_sim-TChiWZ`, as in `external/collider-bench/ColliderBench/tasks/`): what the task asks for, links to its paper and HEPData, and `ledger.yaml`, the correct normalization record filled by hand.

**Public sources only** (paper, HEPData, Prospino), never Collider-Bench's hidden answers. These ledgers are effectively answer keys: never mount or copy `tasks/` into the test-subject's container.
