- **Data:** CMS 2016, 35.9 fb⁻¹.
- **Sources:**
  - CMS-SUS-16-046 Additional Table 2: the signal cut flow for exactly this point, an image or PDF on the CMS public results page.
  - σ: the LHC SUSY Cross Section WG NLO+NLL gluino table (2019 archive copy; see `ledger.yaml`).
- **Note:** the cut flow's first row implies σ 5.7% below the WG value (see `ledger.yaml`, notes).
